Cross-Device Fallback Authentication

You landed on the unauthenticated fallback endpoint for testing the draft crossDeviceFallbackUrl WebAuthn extension (W3C WebAuthn PR #2380).

In a hybrid cross-device authentication flow, a remote device (such as a phone or tablet) opens this URL after user consent when no matching passkey is found on the device. The initiating browser session should receive a WebAuthnOperationException with operationError: "cross-device-fallback".

Security Notes (RFC 10027)

  • This endpoint responds with Cache-Control: no-store, Referrer-Policy: no-referrer, X-Frame-Options: DENY, and a strict Content Security Policy (zero external scripts).
  • All displayed query parameters are HTML-escaped and no automatic redirects are performed.
  • Production Relying Parties must not accept fallback authentication assertions unless the primary WebAuthn ceremony rejected with WebAuthnOperationException (operationError === "cross-device-fallback"), and should use short-lived, single-use session tokens per RFC 10027.
